Ce este GitHub?

Cea mai mare platformă de hosting din lume pentru cod sursă și colaborare software bazată pe sistemul Git.

Git vs GitHub

Git este sistemul local instalat pe calculatorul tău. GitHub este serviciul în cloud unde salvezi și partajezi proiectele.

Comunitatea Open Source

Milioane de dezvoltatori colaborează gratuit la aplicații, librării și proiecte transparente pentru toată lumea.

Despre GitHub și Conceptele Cheie

GitHub a fost fondat în 2008 și este în prezent o companie subsidiară Microsoft. Este utilizat de peste 100 de milioane de dezvoltatori și companii pentru a stoca, gestiona și urmări modificările din codul lor sursă.


Termeni și funcționalități importante:

  • Repository (Depozit / Repo): Folderul virtual al proiectului tău care conține fișierele, istoricul și versiunile codului.
  • Commit: O salvare/fotografie instantanee a modificărilor efectuate în fișiere.
  • Branch (Ramură): O versiune paralelă a depozitului tău pentru a lucra pe funcționalități noi fără a strica codul principal.
  • Pull Request (PR): O cerere oficială de a îmbina modificările dintr-o ramură în proiectul principal.
  • GitHub Actions: Instrument automatizat de integrare și livrare continuă (CI/CD) pentru testarea și publicarea codului.

Ghid Esențial de Comenzi Git

1. Inițializarea unui depozit local

Creează un depozit Git nou în directorul curent.

git init

2. Clonarea unui proiect existent de pe GitHub

Descarcă o copie locală a unui proiect din cloud.

git clone https://github.com/utilizator/nume-proiect.git

3. Adăugarea și salvarea modificărilor (Commit)

Pregătește fișierele modificate și creează o salvare cu mesaj.

git add .
git commit -m "Mesajul tău explicativ despre modificări"

4. Trimiterea modificărilor pe GitHub

Urcă commit-urile din calculator pe serverul GitHub.

git push origin main

5. Descărcarea celor mai recente modificări

Actualizează codul local cu ce au lucrat colegii tăi pe GitHub.

git pull origin main
